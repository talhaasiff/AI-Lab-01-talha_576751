# Fractal Tree & Apparel Design Composition
AI DESIGN LAB 01
**Description:** 
A programmatic visual composition generated for Design Lab 01. This project uses mathematical recursion and iteration to draw a fractal tree from scratch. The generated visual asset was then extracted and applied to a dark maroon t-shirt mockup to demonstrate the creative application of computational geometry in apparel design.

### Fractal Types Implemented
* **Recursive Branching Tree:** The trunk and branches are built using mathematical recursion. Each branch splits into two smaller child branches with reduced length, incorporating an organic angle jitter for a natural look.
* **Iterative Leaf Clusters:** Once the recursion reaches its maximum depth (the base case), the terminal coordinates are saved. An iterative loop then scatters green leaf particles around these exact endpoints.

### Tools, Languages, and Libraries Used
* **Programming Language:** Python 3
* **Environment:** Google Colab
* **Libraries:** `matplotlib.pyplot`, `math`, `random`
* **Design:** External graphic editing tools were used to composite the transparent fractal output onto the dark maroon shirt mockup.

### Setup and Run Instructions
1. Open the `.ipynb` notebook file in Google Colab.
2. Ensure the required libraries (`matplotlib`, `math`, `random`) are available (they are pre-installed in standard Colab environments).
3. Click the **"Run cell"** (Play) button on the code block.
4. The static fractal tree will render immediately in the output section below the cell.
